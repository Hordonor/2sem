# Практична робота №1: Делегати в C#

Реалізація практичної роботи з теми «Делегати в C#» (Вбудовані делегати, калькулятор, мультикастинг, фільтрація, логування та валідація тексту).

## Як запустити
1. Встановіть .NET SDK 8.0 або новішої версії.
2. Перейдіть до папки проекту:
   ```bash
   cd lpr1
   ```
3. Запустіть програму:
   ```bash
   dotnet run
   ```

# Практична робота №6: Потоки та обробка клавіш

Консольний додаток із лічильником у основному потоці та обробкою клавіш у фоновому (`Thread`).

## Бінди
- **P** — пауза / продовження лічильника
- **R** — скинути лічильник до 0
- **C** — змінити колір тексту
- **Q** — завершити програму

## Як запустити
1. Встановіть .NET SDK 8.0 або новішої версії.
2. Перейдіть до папки проекту:
   ```bash
   cd lpr6
   ```
3. Запустіть програму:
   ```bash
   dotnet run
   ```
